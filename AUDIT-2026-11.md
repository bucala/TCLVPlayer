# Audit TCLVPlayer, 11. 11. 2026

## Výsledok a rozsah

Dokončený bežný audit, nie samostatný hlbkový penetračný audit. Zmeny sú v pracovnom branche `droid/audit-a-optimaliz-cia`; nič nebolo commitnuté, publikované ani nasadené. Používateľské playlisty, účty ani zálohy neboli použité.

Kontrola pokryla dátové a prehrávacie toky `app.js`, `web/bridge-player.js`, `web/bridge-client.js`, oba endpointy `api/`, všetky produkčné moduly `bridge/` a `lib/`, Electron main/preload, natívne Android Java helpery a XML resources, build/inštalačné skripty, manifesty/lockfile, Vercel konfiguráciu a GitHub workflows. Kontrolované boli validácia vstupov, XSS/SSRF, hranice IPC/párovania, súkromie, limity zdrojov, súbeh a výkon. Testy slúžili ako dôkaz; generovaný a vendorizovaný kód nebol kompletne ručne auditovaný.

## Závislosti a supply chain

Prvá aktuálna kontrola `npm audit` našla **13 hlásených položiek: 1 high, 12 moderate**, prevažne v build/dev strome. Cielené opravy:

- `follow-redirects` 1.16.1 → 1.16.3;
- `fast-uri` 3.1.8 → 3.1.9;
- `rimraf` 6.1.3 → 6.1.4, ktorý už používa opravený `glob` 14.0.5;
- úzky override iba pre zraniteľné `minimatch >=7 <11.0.1` na 11.0.8; vetvy 3 a 5 zostali zachované.

Zámerne nebol použitý `npm audit fix --force` ani navrhovaný downgrade ESLintu. Priama verzia aplikácie, Electronu a prehrávacích knižníc sa nemení. Interný minimatch prešiel na novú hlavnú vetvu; jeho Node požiadavky spĺňa už existujúce minimum projektu. Kompatibilita bola kontrolovaná lintom, testami aj produkčným bridge buildom.

**Výsledný `npm audit`: 0 známych zraniteľností.** To nie je dôkaz neprítomnosti všetkých chýb. Lockfile zachováva HTTPS registry URL a integrity hashe; pri inštalácii opráv boli lifecycle skripty vypnuté.

**[P1] [security] [SUPPLY-CHAIN] Nová mladá tranzitívna verzia:** opravený minimatch priviedol `@isaacs/nonrecursive-glob-match@1.1.0`, publikovanú 5. 11. 2026, menej než sedem dní pred auditom. Samotný balík vznikol 26. 10. 2026. Ide o deklarovanú upstream závislosť minimatch pod menom jeho autora; skontrolovaný bol manifest, vstupný matcher, absencia install/postinstall hookov a zamknutá integrita. Počet stiahnutí nebol získaný, npm metadata lookup ho neposkytuje. Mladý release zostáva supply-chain rizikom na kontrolu pred merge, nie potvrdeným škodlivým balíkom; nulový advisory audit toto riziko nevylučuje.

## Nameraný výkon

Windows, Node 24, Playwright Chromium. Každý variant v čerstvom browser procese nad skutočným Vercel buildom, bez osobných dát a s blokovanými externými požiadavkami:

- 5 000 kanálov, 48 programov na kanál, **240 000 programov**;
- produkčné indexovanie a skutočné `renderChannels()`/`renderGuide()`;
- 70 kariet, 70 EPG riadkov, **1 120 viditeľných programov** pred aj po zmene;
- tri po sebe idúce vykreslenia, prvé bez zahriatia.

| Čas samotného renderovania | Pred optimalizáciou | Po optimalizácii |
| --- | ---: | ---: |
| EPG, prvé volanie | 385,9 ms | 63,7 ms |
| EPG, druhé volanie | 375,7 ms | 44,0 ms |
| EPG, tretie volanie | 366,6 ms | 39,0 ms |
| Kanály, prvé volanie | 23,1 ms | 23,1 ms |

V poslednom meraní je najpomalšie EPG volanie približne **6,1× rýchlejšie**, čas klesol o približne **83 %**. Predchádzajúce finálne overenie nameralo 68,8 / 36,9 / 39,7 ms, teda aj pri horšom prvom volaní približne 5,6× zrýchlenie. Vykreslenie kanálov nevykazuje spoľahlivé zrýchlenie, jeho počet DOM uzlov zostáva ohraničený. Čísla nezahŕňajú stiahnutie/parsing EPG, indexovanie ani build; nie sú meraním celého štartu aplikácie, mobilného TV ani Core Web Vitals. Hardvérové a plánovacie rozdiely ovplyvňujú absolútne časy.

Reprodukcia: zostaviť webový bundle a spustiť `npm run test:performance`. Script neprepíše používateľské dáta; generuje ich iba v novom testovacom browser kontexte. Je to benchmark, nie časový gate CI s nestabilným limitom.

## Nové webové prehrávanie cez Vercel

Predvolene vypnuté, pri prvom zapnutí potvrdenie, viditeľné varovanie o mesačnom prenose, priame → Vercel a iba Vercel režimy, lokálna perzistencia a orientačný mesačný odhad. Lokálny bridge netreba; source proxy pre EPG/playlisty zostáva oddelený. Natívne aplikácie tento modul nenačítajú.

`api/stream.js` používa overenie každej cieľovej adresy a DNS odpovede, pripnuté origin pools s minútovou obnovou, kontrolované redirecty, zrušenie pri odpojení, obmedzené manifesty, Range a časové/súbežné limity. Médiá sa streamujú, nie celé ukladajú do RAM. Aplikácia neposiela cookies/Authorization prehliadača poskytovateľovi ani serverovo necachuje súkromné streamy.

Dátové cesty, súkromie a limity sú podrobne v [WEB-PLAYBACK.md](WEB-PLAYBACK.md). Vercel región je `fra1`; geografické zlepšenie latencie na nasadení nebolo merané.

## Zostávajúce hranice a riziká

1. **Vercel podmienky:** [proxy patrí medzi Never fair use](https://vercel.com/docs/limits/fair-use-guidelines#never-fair-use) aj na platených plánoch. Technická implementácia ani warning nezaručujú povolenie služby. Pred nasadením treba súhlas/overenie podmienok; nič nebolo nasadené.
2. **Prenos a zneužitie:** Hobby uvádza 10 GB origin a 100 GB CDN prenosu, plus limity funkcií. Origin/Sec-Fetch hlavičky nie sú autentifikácia pre podvrhnutého klienta a procesové kvóty nie sú globálny rozpočet. Odporúčané sú prístupové a rozpočtové opatrenia hostingu. `TCLV_VIDEO_RELAY=off` vypína endpoint po novom nasadení.
3. **Súkromie:** Vercel dostane aj provider URL s prípadným heslom v query; môže byť súčasťou platformových access logov. Lokálny odhad prenosu nie je billing ani globálna kvóta.
4. **Kontinuálne streamy:** funkcia končí po 280 s a TS/FLV klient sa znovu pripojí; možný krátky výpadok. Funkcia má vo Verceli maximum 300 s. DRM, transkódovanie, full LL-HLS, content steering a poskytovateľské blokovanie dátových centier nie sú vyriešené.
5. **Bridge kapacita:** globálny pool má 10 000 ticketov. Manifest s viac než 9 999 odlišnými zdrojmi dostane 413. Väčší súbeh prehliadačov môže vytlačiť staršie tikety iného streamu; LRU nie je neobmedzená garancia celého VOD katalógu.
6. **Neoverená platforma:** neprebehlo nové zostavenie APK/Electron aplikácie, spustenie Windows inštalátora, fyzický Android TV test ani test nasadeného Vercelu. Browser testy nezaručujú kompatibilitu všetkých poskytovateľov, kodekov a TV firmvérov.
7. **Natívne logá:** 512-pixelový limit výstupného Android artworku sám osebe nedokazuje limit stiahnutých bajtov. Bez preverenia konkrétnej Media3 implementácie a zariadenia to nie je potvrdený bezpečnostný nález; zostáva oblasť na doplňujúci native test.
8. **Importy:** importovanému nastaveniu vzdialeného source proxy treba dôverovať, pretože po obnovení môže dostať URL s prihlasovacími parametrami. Na malých zariadeniach zostáva import celej veľkej JSON zálohy pamäťovo náročný.

Zdroje platformových limitov boli overené 11. 11. 2026: [Hobby](https://vercel.com/docs/plans/hobby), [Functions limits](https://vercel.com/docs/functions/limitations), [Fair use](https://vercel.com/docs/limits/fair-use-guidelines).
